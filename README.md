**Usage:**  
`Rscript SSM2-Single-Cell-Analysis.R [-h 2 3 4 5 6 7]`

**ARGUMENTS:**  
- **default**: If no value is given, generates all figure images  
- **-h/--help**: Prints this help message  
- **2-7**: Generates those figure images. Multiple numbers can be entered.

**EXAMPLE:**  
To generate images for figures 3 and 7:  
`Rscript SSM2-Single-Cell-Analysis.R 3 7`
